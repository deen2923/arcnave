# ARCNAVE

NASA Space Apps Challenge 2026, "Planet X and SPHEREx". Type any RA/Dec (or a name) and NASA's real SPHEREx images of
that spot play like a film; stars that move are circled pass by pass and measured, checked against ESA Gaia DR3 and
NASA WISE (CatWISE2020). Every number is measured by the code on the real archive data; nothing is called a discovery.

The 5 NASA test targets: add `#ct=barnard`, `#ct=epsindb`, `#ct=wise0855`, `#ct=rwaur` or `#ct=rdra` to the address.

Data: NASA/IPAC IRSA (SPHEREx), ESA Gaia DR3, NASA WISE/CatWISE2020, CSA NEOSSat via CADC, IMCCE SkyBoT, Minor Planet
Center, JPL Horizons, CDS. Full credits: `/about.html`.
